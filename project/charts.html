Charts

C#
WinForms
.NET

> Об утилите

Charts — это прикладное ПО для визуализации данных в виде графиков и диаграмм. Позволяет создавать и настраивать различные типы графиков для анализа телеметрических данных.

Разработано для участия в Всероссийском чемпионате «ВИШ».

> Системные требования

ОС: Windows 10 (1809+)
Библиотека: .NET 4.7.2+
